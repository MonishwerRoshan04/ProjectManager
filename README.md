# 🚀 Let's Build - Product Management Learning & Career Platform

A modern, responsive EdTech & SaaS landing page designed to help aspiring and experienced professionals accelerate their Product Management careers through structured certification programs, mentorship, and practical assessments.

## 🌐 Live Demo
- **Netlify Live URL:** [View Live Website](https://project-managerui.netlify.app/) 

## ✨ Key Features
- **Structured Certification Tiers:** Showcases progressive learning tracks (*Product Manager*, *Product Leader*, and *Product Executive* certificates) with duration, module breakdowns, and target audience details.
- **Interactive Skill Assessment CTA:** Dedicated evaluation section allowing users to test their product thinking and problem-solving skills.
- **Value Proposition Highlights:** Clean feature cards highlighting *Live Online Classes*, *Applied Projects*, *1-on-1 Mentorship*, and *Industry-Recognized Certification*.
- **Dynamic Testimonial Slider:** Showcases real learner success stories with star ratings and smooth interactive navigation.
- **Interactive Modals & Form Validation:** Seamless user flows for test-taking, program enrollment, and contact inquiries.
- **Fully Responsive Design:** Built mobile-first with smooth animations and clean visual hierarchy across all screen sizes.

## 🛠️ Tech Stack
- **HTML5:** Semantic and accessible page structure.
- **CSS3:** Custom styling, Flexbox, CSS Grid, and modern UI gradients.
- **Bootstrap 5:** Responsive grid system and layout components.
- **Vanilla JavaScript (ES6+):** Interactive testimonial slider, dynamic modals, and client-side form validation.
- **AOS (Animate On Scroll):** Smooth scroll-triggered animations.
